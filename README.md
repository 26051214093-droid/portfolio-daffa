# Portofolio Daffa Barca Putra Christilla

Website portofolio statis berdasarkan CV dan Guidebook Website yang diberikan.

## Isi folder
- `index.html` — struktur dan konten website.
- `styles.css` — desain visual responsif desktop/tablet/ponsel.
- `script.js` — menu mobile, tahun otomatis, dan animasi ringan yang menghormati prefers-reduced-motion.
- `assets/CV_Daffa_Barca_Putra_Christilla.pdf` — salinan CV yang disediakan.
- `assets/favicon.svg` — ikon tab.
- `screenshots/` — screenshot hasil render untuk laporan.

## Menjalankan website di laptop
1. Ekstrak ZIP.
2. Buka folder `portfolio_daffa` di Visual Studio Code.
3. Jika Live Server terpasang, klik kanan `index.html` → **Open with Live Server**. Alternatifnya, buka `index.html` langsung di browser.

## Menerbitkan agar bisa diakses publik
1. Buat/login ke akun GitHub milikmu dan buat repository baru bernama `portfolio-daffa` dengan visibilitas **Public**.
2. Unggah seluruh isi folder ini (pastikan `index.html` berada di root repository), lalu lakukan commit.
3. Buka **Settings → Pages**.
4. Pada bagian build/deployment, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu **Save**.
5. Tunggu sampai GitHub Pages menampilkan URL aktif di halaman Settings → Pages. Uji URL itu dari jendela incognito atau perangkat lain.

Profil GitHub: https://github.com/26051214093-droid. URL website publik tetap belum bisa dicantumkan sebelum repository website dibuat dan GitHub Pages diaktifkan melalui akun pemilik.

## Hal yang perlu diperbarui sebelum/ketika publikasi
- Pastikan keputusan untuk menampilkan nomor WhatsApp dan alamat email secara publik sudah sesuai keinginan.
- Profil GitHub yang ditampilkan: https://github.com/26051214093-droid.
- Tambahkan pencapaian/sertifikat hanya jika ada bukti yang benar.
- Tambahkan screenshot proyek atau tautan demo ketika sudah tersedia.

Website ini tidak memakai backend/server form; tombol kontak membuka aplikasi email, LinkedIn, atau WhatsApp pengguna.
